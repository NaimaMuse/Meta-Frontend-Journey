# 🌐 Course 1: Introduction to Front-End Development

**Provider:** Meta  
**Estimated Time:** 19 Hours  
**Status:** ✅ Completed  

---

## 📌 Course Overview
This course provides a foundational entry point into web development, exploring the day-to-day responsibilities of a front-end developer alongside the core technologies that power the modern web.

---

## 🎯 Key Learning Outcomes
- **The Front-End Role:** Understood the responsibilities and workflows of modern web developers.
- **Internet Fundamentals:** Explored how browsers, servers, HTTP, and core web architecture communicate.
- **Core Building Blocks:** Learned to write structural HTML and apply CSS for styling and layout control.
- **Modern UI Tools:** Introduced to popular UI frameworks (Bootstrap) and JavaScript libraries (React) for building dynamic user interfaces.

---

## 🛠 Skills & Technologies Learned
- **Languages:** HTML5, CSS3
- **Frameworks & Libraries:** Bootstrap, React (Overview)
- **Concepts:** Responsive Web Design, Grid Systems, DOM Basics, Web Architecture

---

## 🏆 Final Project
**Responsive Webpage with Bootstrap**
- Designed and built a mobile-responsive webpage containing formatted text and media assets.
- Implemented Bootstrap’s **responsive grid layout system** to ensure clean presentation across desktop, tablet, and mobile screens.
