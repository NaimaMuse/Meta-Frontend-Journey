# 🔀 Course 3: Version Control

**Provider:** Meta  
**Estimated Time:** 16 Hours  
**Status:** ✅ Completed  

---

## 📌 Course Overview
This course covers how modern software developers collaborate globally using version control systems. It provides hands-on practice with Linux CLI navigation, Git workflows, and GitHub repository management to prevent code conflicts and build efficient, automated development workflows.

---

## 🎯 Key Learning Outcomes
- **Collaborative Workflows:** Understood how distributed teams collaborate globally without overwriting or breaking each other's codebases.
- **Linux Command Line:** Mastered essential Linux terminal commands for fast file navigation, directory management, and workflow automation.
- **Git Revision Control:** Learned how to initialize local repositories, track changes, stage files, and manage revision histories.
- **Branching & Merging:** Practiced isolation of features using Git branches, resolving merge conflicts, and syncing changes via remotes.

---

## 🛠 Skills & Tools Learned
- **Tools:** Git, GitHub, Command Line / Terminal (Bash)
- **Linux Commands:** `ls`, `cd`, `mkdir`, `rm`, `cat`, `grep`, `pwd`
- **Git Commands:** `git init`, `git add`, `git commit`, `git status`, `git branch`, `git merge`, `git checkout`/`git switch`, `git push`, `git pull`
- **Concepts:** Distributed Version Control Systems (DVCS), Branching Strategies, Merge Conflicts, Remote Repositories

---

## 🏆 Final Project / Key Milestones
- Created and configured a version-controlled software repository.
- Practiced executing branching strategies, committing incremental feature changes, and resolving code revisions using Git and GitHub.
